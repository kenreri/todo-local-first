## 执行约定

使用固定源 `http://127.0.0.1:5173/`。涉及数据覆盖、迁移、清缓存或模拟大量数据时，用独立测试浏览器配置和可丢弃库；不要清空日常使用数据。只删除自己创建的具名测试记录。PWA 在生产构建上验证，开发服务器不启用 PWA。

每次验收记录日期、提交/工作区版本、浏览器与系统、场景、期望/实际结果和证据。未运行、工具失败、验证通过应分开记录；历史工具故障不直接沿用为今天的结论。

- [ ] 收集 → 编辑 → 注入保存失败 → 保留草稿和切换目标 → 重试成功 → 切换 → 创建关联任务 → 刷新持久化；创建任务前先保存文字，成功后留在原记录。
- [ ] 轻输入不强制标题/日期/任务；安排日与 DDL 独立；最近默认 7 天，搜索跨最近范围，站内切页保留筛选、浏览位置和文字草稿。

- [ ] JSON v1/v2/v3/v4 导入兼容，导出 v4 的业务集合与附件原始字节正确；CSV 只验证任务导出，不假定可导入。
