# TODO 清单

一个本地优先的个人任务管理应用。用清单和日历安排任务，用番茄钟记录专注时间，也可以在同一个应用里打卡和追踪番剧进度。

## 功能

| 功能 | 可以做什么 |
| --- | --- |
| 今天与任务 | 在今天页查看待办，使用清单、列表和日历整理任务。支持子任务、标签、优先级、重复规则和批量操作。 |
| 专注与回顾 | 将番茄钟关联到任务，查看专注时长和任务完成情况。 |
| 习惯与看番 | 记录习惯打卡、追番状态和观看进度。番剧搜索使用 Bangumi，需要联网。 |
| 外观与使用方式 | 支持浅色和深色主题、中英文界面、键盘快捷键以及在支持的浏览器中安装为 PWA。 |
| 数据备份 | 导出和恢复 JSON 备份，也可以把任务导出为 CSV。 |

## 本地运行

使用 Node.js 24 和 pnpm 11.23.0。

```bash
pnpm install --frozen-lockfile
pnpm dev
```

在浏览器中打开 `http://127.0.0.1:5173/`。应用启动需要 5173 端口。首次使用时，可以直接新建清单和任务。

Windows 也可以在安装依赖后，从项目目录运行以下命令启动应用。

```powershell
powershell -NoProfile -File .\scripts\Start-Todo.ps1
```

## 数据保存与恢复

任务、习惯、番剧、专注记录和设置保存在当前浏览器的 IndexedDB 中。日常使用请保持相同的浏览器配置和访问地址。浏览器会为 `localhost`、`127.0.0.1` 以及不同端口分别保存数据。多端同步列在开发路线图中。

在应用设置中导出 JSON，可在更换设备或清理浏览器数据前保留备份。导入 JSON 会替换当前应用数据，请先导出当前数据。CSV 用于在电子表格中查看任务。

## 开发与验证

界面使用 React、TypeScript 和 Tailwind CSS，Vite 负责开发服务和生产构建。Zustand 管理界面状态，Dexie 读写 IndexedDB。

```bash
pnpm lint
pnpm test
pnpm build
```

构建结果位于 `dist/`。部署后，浏览器可在 HTTPS 环境中注册 Service Worker，缓存应用资源以便离线打开。
